# Rocco's Garage

a toddler tire-swapping game. cars roll into the garage, tap a tire to pop it off, tap a new tire on the rack to put it on. swap all four and the car honks, flashes its lights, and drives off happy.

- no scores, no timers, no fail states - every tap does something fun
- tire options: classic, monster, rainbow, donut, star
- sounds are generated in code with webaudio (pops, ratchet clicks, honks, a cheer) - no audio files
- single self-contained `index.html`, just open it or serve it statically
